# math-concept-film · 会讲数学的 AI 动画短片工厂

> **你说一个概念，AI 还你一部带中文配音的动画短片。**

这是一个给 AI 编程助手（Claude Code / Codex / WorkBuddy 等）用的技能（skill）。
装好之后，你只需要对 AI 说一句人话：

> "帮我用视频讲清楚傅里叶级数"
> "把泰勒公式做成动画"
> "讲讲链表是什么，做成视频"

几分钟后，你会得到一部 **2~5 分钟、纸墨手账质感、中文配音、带字幕** 的
`final.mp4`。

b 站成片示例：https://www.bilibili.com/video/BV1ws4R6fEHh/

## 你会得到什么？

一条流水线跑完，产出 `final.mp4`：**画面 + 中文旁白 + 烧录字幕**，直接能发。

- 📜 **宣纸暖底、墨色笔触**——像一本会动的数学手账，不是炫酷科技风
- 🎙️ **中文旁白**——微软云声线，语速调过，不催眠
- ✍️ **会讲的手**——标题和公式一笔一笔"写"出来，三角形块搬运拖着墨迹走
- 🎬 **镜头会讲课**——讲局部就推近，讲完拉回全景，高潮处涟漪爆点定格
- ✅ **数学保真**——画面上每个数字都验算过，每个"所以"都有前因

## 三步装好

```bash
# ① 把本文件夹放进你的 AI 助手能读到的 skills 目录
# ② 装依赖（一条命令）
pip install -r requirements.txt        # = manim + edge-tts + imageio-ffmpeg

# ③ 体检（可选但推荐）
python scripts/doctor.py --full
```

然后对 AI 说"把 XX 概念做成视频"就行。**AI 负责干全部活**：
写台词 → 合成配音 → 量出每句话的精确时长 → 按时长编排动画 → 渲染 → 自检 → 出片。
你唯一要做的事：**验收**。不满意就指出"第 X 秒节奏太快"，它会返工。

## 它是怎么工作的？

```
你的概念 ──▶ AI 写台词 ──▶ AI 配音 + 量时长
                                    │
     final.mp4 ◀── 混流合成 ◀── 渲染动画 ◀── 按真实时长设计画面
```

关键设计：**先配音、后画面**。每句旁白的精确秒数先量出来，画面严格按秒编排，
不会出现"话说完了图还没画出来"的错位。

### 为什么这套片子不无聊？（2026-11 吸引力改版）

早期版本被用户批评"无聊"。复盘找到根因后写成了宪法硬指标，现在的成片必须
过这些检查才准交付：

| 设计 | 说明 |
|---|---|
| 前 5 秒法则 | 开场就有动画在"演"问题，不许静态标题独占画面 |
| 问题要演不要写 | 概念用动画发生（拼图重排、光点游走），不是文字贴片 |
| 结构动画 ≥40% | 画面主体是"被操作的图形"，不是一堆文字框 |
| 节奏对比 | 快节拍（0.4s 连招）和定格蓄力（2s hold）交替，拒绝匀速催眠 |
| 高潮定格 | 每片至少一处涟漪爆点 + 结论定格 |
| 版面利用率 | 抽帧实测画面占比，内容缩成一小块 = 返工 |

动效方面：Manim 的 Write（逐笔写）、LaggedStart（齿落登场）、TracedPath（墨迹拖尾）、
流光扫过等表现力动效全部放开，只禁大幅旋转飞入和剧烈弹跳——**克制的是色彩，不是动作**。

## 目录里都是什么？

```
math-concept-film/
├── SKILL.md                 ← 给 AI 读的"操作宪法"（触发词、工作流、硬指标）
├── README.md                ← 你正在看的：给人读的说明书
├── requirements.txt         ← 一条命令装齐的依赖
├── references/              ← AI 的进阶教材
│   ├── cinematography-grammar.md   镜头语言手册（表现力动词表/节奏对比）
│   ├── scene-contract.md           画面质量自查清单（含吸引力条款）
│   ├── pitfalls.md                 血泪坑全集（Manim 坑/排版坑/字体坑）
│   └── template-ds-film.md         数据结构片领域模板（链表/树/排序/DP…）
├── templates/
│   ├── film_skeleton.py     ← 新片起点：可直接渲染，自带动效助手和时钟
│   └── ds/                  ← 数据结构资产包（节点/数组/树/排序积木）
└── scripts/                 ← AI 干活用的哑工具
    ├── doctor.py            环境体检：缺啥装啥
    ├── tts_lines.py         台词 → 配音 + 精确时间轴
    ├── preflight.py         渲染前预检（重叠/越界/坏字符）
    ├── check_film.py        渲染前体检（字幕挂接 + 吸引力检查）
    ├── gen_cap.py           字幕自动折行（每行 ≤18 字，最多 2 行）
    ├── render.py            渲染运行器（自动清缓存、日志、混流）
    └── frame_coverage.py    版面利用率抽帧检查
```

## 常见问题

**Q：一定要联网吗？**
配音环节要（微软在线 TTS，免费）。渲染不需要。

**Q：能换音色吗？**
能。`python scripts/tts_lines.py --list-voices` 列出全部中文声音。

**Q：能出高清吗？**
能。默认 480p（渲染快）；对 AI 说"要高清版"，它会用 720p/1080p 重渲。

**Q：能讲数据结构/算法吗？**
能，而且是强项。链表、哈希表、树、图、排序、递归、动态规划都有专门的
视觉积木（节点、数组条、内存网格、树布局）和九幕叙事模板。

**Q：体检报错怎么办？**
`python scripts/doctor.py` 的输出会精确告诉你缺什么、复制哪条命令能装上。
