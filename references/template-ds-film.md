# 数据结构/算法片领域模板（原 ds-algo-film 精华）

做数据结构、算法讲解片（链表/栈队列/哈希表/树/图/排序/DP/回溯…）时，
在主 SKILL.md 流水线之上叠加本模板。

## 开工差异

```bash
cp <skill>/templates/film_skeleton.py film.py
cp <skill>/templates/ds/{assets.py,treelib.py,sortlib.py} .
# film.py: from assets import * ；Scene 继承 ThreeDScene + FilmClock
# 字幕：gen_cap.py 从 lines.json 生成 cap_block.py（自动折行、防重复 id）
python <skill>/scripts/gen_cap.py lines.json -o cap_block.py
# 体检：check_film.py 追加字幕挂接/时钟/吸引力检查
python <skill>/scripts/check_film.py film.py lines.json captions/aligned.json
python <skill>/scripts/render.py <项目目录> <SceneName> --mux
```

范围规则：只做有教学内容的小节（定义/实现/操作/原理）；`小结`、`练习`、`index`
跳过不制作，也不要在结尾预告。

## 九幕叙事模板

| 幕 | 回答什么 | 视觉主意 |
|---|---|---|
| 1 钩子 | 上一节的痛点/悬念问句 | **问题现场演出来**（失败演示/反直觉现象），标题叠加不独占 |
| 2 动机 | 物理视角：内存为什么需要它 | 内存网格（mem_empty_grid），"东一块西一块" |
| 3 解剖 | 核心单元内部 + 最小代码 | punch_in 推近变焦进单元，逐部件 indicate 圈注 |
| 4 构建 | 从零分步建出结构 | lagged_in 逐个登场 → 引用/边级联生长（traced_move） |
| 5-7 操作 | 每幕一个核心操作(增/删/查) | 结构就位 → 代码 chip 与动画联动 → 下半屏对比"朴素方案" |
| 8 变体 | 变体家族 | 2~3 行小号结构横排，每行一个动效点睛 |
| 9 总结 | 对比表 + 工程应用 | 表格逐格高亮，应用 chips 按变体分色，大字+burst 定格 ≥2s |

台词纪律：每幕 2~4 句，承接词开头；每个"所以"有前因；`O(1)/O(n)` 不进台词
（旁白说"常数时间"，记号只上画面）。台词平均 7s/句，用于估算幕预算。

## 数据结构视觉语言（观众看得懂的约定，assets.py 已内置）

- **节点** = 圆角矩形两格：左格值、右格引用点(INDIGO)。`assets.Node`
- **引用/指针** = `ref_arrow` 射向下一节点；被替换的旧引用先转虚线(`dash_arrow`)
  再消失——"改接"看得见；游走用 `traced_move(glow_dot, …)` 拖墨迹
- **代码↔画面联动** = `chip("P.next = n1")` → 对应箭头生长 → chip 变 STONE 绿
- **遍历** = glow_dot(AMBER) 沿节点移动 + `①②③④` 徽章计数
- **删除** = 节点灰化(GRAY)+opacity 0.5+下沉；"不可达"用光点直达后继证明
- **对比** = 上半屏新结构、下半屏 `array_row`；数组搬移必须从队尾级联（见 pitfalls 六-2）
- **结论/正确** STONE 绿 · **焦点** AMBER · **删除/警示** VERM · **指针** INDIGO

## 教学手法工具箱（标杆：ds45-introdp《初探动态规划》，用户验收认可）

- **悬念钩子**：开场抛问题不给答案，结尾才回收
- **拟人道具**：抽象机制配具体物件（记忆化=小本本，剪枝=掉头，哈希表=通讯录）
- **算账可视化**：复杂度对比写成"谁 vs 谁"两个大 chip + 大箭头
- **大数字翻译**：指数/阶乘立刻跟人话（宇宙毁灭/百亿亿条路）
- **先错后对**：直觉做法先上屏，让坑自己暴露，再引正解
- **口诀收尾**：全片最后一句 ≤14 字、能背走（"前序找根，中序分家"）

叙事十二幕样例（ds45）：抛问题(60级台阶,不给答案) → 小数字找感觉 → 关键一问
→ 记下规律(公式=口头规律的书面化) → 照式子拆 → 踩坑(2^60"宇宙毁灭也算不完")
→ 小本本(记忆化拟人化) → 大跳水(2^60→60次) → 从底往上填表(此处才第一次说出
"动态规划") → 三个名词挂在刚见过的东西上 → 滚动变量 → 一句能背走的话。

## 吸引力硬标准（本领域特别强调）

历史 AST 审计实证：ds26/ds27/ds44/ds46/ds48/ds49 结构动画为 0%（纯 chip）。
主 SKILL 的 40% 门槛在本领域尤其容易翻车，追加两条：

- 规则：**每个"过程类结论"必须在结构上演出来，不许用 chip 贴结论**
  （"每行只放一个皇后"→ 演两个皇后同排闪红；"选过不能再选"→ 演牌子跳过）
- 冲突/回退/失败必须可视化（红 X、攻击线、皇后飞走），成功用石绿固化
