# 镜头动词手册 v2（表现力版）

核心思想两句话：
**相机就是旁白员**——画面永远在替台词做"看哪里、看多近"的决定。
**克制的是色彩，不是动作**——纸墨风的高级感来自墨色与构图，活力来自节奏与动效。
（2026-11 改版：4 动词白名单已废除，改为负面清单；匀速节奏判定为"催眠"事故。）

## 动效负面清单（唯一禁令）

- ✗ 大幅旋转飞入（>90° 转圈进场）
- ✗ 剧烈弹跳（多次 overshoot 的晃动）
- ✗ 无意义晃动 / 为动而动
- ✗ 五色同场、相机全程乱动（观众晕）

清单之外的全部放开，骨架已封装成助手（film_skeleton.py，自动记账时钟）：

## 表现力动词表（按用途查）

| 动词 | 什么时候用 | 助手 | 备注 |
|---|---|---|---|
| **WRITE 逐笔写** | 标题/公式/关键词登场——手账感招牌 | `write_in(mob)` | 长文本别用（慢）；每幕 ≤2 次 |
| **LAGGED 齿落** | 一组格子/块/项群体登场 | `lagged_in(*mobs, lag=0.15)` | 数组、表格、步骤列的标配 |
| **POP 小弹** | 快节拍(0.4s级)单个元素登场 | `pop_in(mob, rt=0.45)` | rush_from 减速落地，不弹跳 |
| **TRACED 墨迹** | 指针游走/块搬运——移动的灵魂 | `trail = traced_move(mob, mob.animate.move_to(p))` | 移动结束轨迹淡出 |
| **SWEEP 流光** | 强调"这条线/这个面" | `sweep(curve)` | 每幕至多一次 |
| **INDICATE 圈点** | 轻强调（外框一闪） | `indicate(mob)` | 替代文字注释 |
| **BURST 涟漪** | 高潮爆点（结论/最大转折） | `burst(mob)` | 全片 1~2 处，配 ≥2s 定格 |
| **IRIS 墨渍转场** | 幕间换景 | `disc = ink_iris(); …; ink_iris_out(disc)` | 盘下静默 add 新幕内容 |
| **PUNCH 推近** | 讲局部 | `punch_in(target, zoom=2.0)` | 1.2~1.6s，讲完必 pull_back |
| **PULL 回归** | 局部讲完回全景 | `pull_back()` | 成对出现，不许丢在局部 |
| **HEADLINE 宣言** | 幕首（叠加在演示上，不独占屏） | `headline(self, txt, write=True)` | 钩子幕标题后置 |
| **TERM TOUR 巡讲** | 多项公式逐项讲透 | spotlight 循环（聚光→推近→回归） | 每站 ≥1.4s |
| **SET PIECE 真 3D** | 场/曲面/旋转体 | `move_camera(phi=65*DEGREES…)` | 文字永远 fixed_in_frame |

底层动词自由使用：`Transform` / `ReplacementTransform` / `TransformMatchingShapes` /
`GrowFromEdge` / `Flip`（小幅）/ `rate_functions`（`rush_from` 快出缓停、`rush_into`
缓入加速、`there_and_back_with_pause` 去而复返、`lingering` 拖尾）。updaters 用于
标签实时跟随移动点（`always_redraw`）。

## 节奏对比（v2 核心：禁匀速）

匀速 = 催眠。每幕内部用三档速度编织：

| 档 | 时长 | 用在哪 |
|---|---|---|
| 快节拍 | 0.4~0.6s/步 | 列举、连锁反应、多步推导、格子系统落位（配 lagged_in/pop_in） |
| 中速 | 1.0~1.4s/步 | 单个新概念登场、图形绘制 |
| 定格蓄力 | 1.5~2s hold | 高潮前、转折点、"猜猜会怎样"的悬念停顿 |

- **高潮定格**：每片至少一处——最强画面 + `burst` + hold ≥2s + 结论字幕。
  通常放在最后一幕（证明完成的一瞬）。
- 快→慢的瞬间就是戏剧点："三步搬完（快）……停——注意中间这块（定格）"。
- 幕末 0.5s 缓冲不上新元素（呼吸口），比旧版 0.8s 紧凑。

## 转场语汇

| 语境 | 手法 |
|---|---|
| 换幕不换景 | 字幕换页 + 旧元素 `Transform` 成新元素 |
| 换幕换景（默认） | `ink_iris` 墨渍吞没 → 静默布景 → `ink_iris_out` 显露（约 0.9s，比全屏 FadeOut 有辨识度） |
| 时间推进 | 相机 zoom 1.0→1.15 极缓推近 |
| 告一段落 | 全场退到只剩结论 + 定格 |

## 光晕与焦点（稀缺资源）

- 光晕点/光晕线：核心对象外围同心递减层——"活着的点"。全片同一时刻至多一处。
- 流光 `sweep`：每幕至多一次。
- 琥珀色只给"当前焦点"。

## 版面（对应吸引力宪法第 6 条）

- 内容包围盒目标 ≥55% 画幅。构图原则：**占满而不要居中漂**——
  大图 + 左右注释列 > 居中小图四周留白。
- 空幕报红：一屏只有 1~2 个文字块且无图形 = 视觉事故，重设计该幕。
- 检查工具：`scripts/frame_coverage.py <video.mp4>`（抽帧算包围盒占比）。

## 反面清单

- ✗ 相机全程都在动——一幕最多两次运镜（推+回）
- ✗ 五个色同时上场
- ✗ 台词没说到的元素提前出现（音画同步抽查会抓到）
- ✗ 一幕从头到尾匀速 FadeIn（催眠事故，2026-11 起视为 bug）
- ✗ 一屏孤零零 1~2 个文字块（版面事故）
- ✗ 3D 场景文字变形——文字永远 add_fixed_in_frame_mobjects
